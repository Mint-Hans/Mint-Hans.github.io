聊 LLM + 游戏的时候，大多数人想到的是：

```
AI 生成剧情
AI 生成关卡
AI 生成NPC对话
```

这些都是 **内容生产者**。

但 LLM 还有一个被忽视的角色：

**内容分发者。**

其实游戏行业早就有人在做这件事了——不是用 AI，是用规则。

Roguelike。

《以撒的结合》《哈迪斯》《杀戮尖塔》——

策划做内容池，随机数做分发，每一局不同。

但随机分发有一个天花板：**它不理解你。**

LLM 要做的，是把 Roguelike 的「随机分发」升级成「智能分发」。

---

## 从 TikTok 说起

TikTok 为什么上瘾？

不是因为它**生产**了最多的视频。

而是因为它**分发**得最聪明。

```
内容池（所有视频）
      ↓
  推荐算法
      ↓
  你看到的视频序列
```

同一个内容池，不同的人刷出不同的 TikTok。

一个看猫，一个看做饭，一个看跳舞。

**内容是一样的，顺序不一样，体验天差地别。**

---

## 但游戏不是 TikTok

TikTok 可以完全交给算法。

因为刷视频是**被动消费**——你躺着，内容流过你。

游戏不是。

游戏是**主动交互**——玩家在「挫折 → 学习 → 突破 → 成就感」的循环里。

这个循环的节奏一旦乱掉，玩家就流失了。

### 《艾尔登法环》是反例吗？

很多人说法环「自由探索」、「碎片化叙事」——

但它的流程**仍然可控**。

```
宁姆格福 → 史东薇尔 → 学院 → 王城 → 雪山 → 天空城 → 灰城
```

你可以绕路，可以先打别的，但——

- 噩兆妖鬼就是放在必经之路上，给你上课
- 接肢葛瑞克就是第一个大 Boss，难度刚好让你觉得自己行了
- 火焰巨人的场地就是空旷的，逼你学会骑马战斗

**碎片化是表象。节奏控制是底层。**

### 《只狼》更明显

```
第一个武士大将 → 教你格挡
鬼形部 → 教你识破
弦一郎 → 期末考试
```

顺序几乎不可变。

为什么？

因为玩家的**情感体验**是有结构的：

```
遇到强敌，反复死
      ↓
慢慢学会看招式
      ↓
第一次完美格挡
      ↓
处决那一刻的爽感
```

这个结构不是自然发生的。

是**设计出来的**。

---

## 所以 AI 不能「自由发挥」

AI 完全自由发挥 = 没有节奏 → 玩家流失。

这不是技术限制。

**是媒介的本质。**

小说有章节结构。电影有三幕剧。游戏有难度曲线。

媒介不同，但都依赖**对信息释放节奏的精确控制**。

所以真正有意义的探索方向，不是「AI 替代策划写剧本」。

而是下面三种。

---

## 游戏里的对应

现在的游戏是这样的：

```
策划设计关卡 1 → 2 → 3 → 4 → 5
                ↓
          所有玩家走同一条线
```

所有人玩到的东西一模一样。

难度曲线是策划拍脑袋定的。

但问题是——

**你凭什么假设所有玩家能力一样？**

---

## 用 LLM 做分发

把 LLM 放进游戏循环里，不是让它写内容。

是让它**决定你接下来看到什么内容**。

```
策划做内容池（100 个任务、50 种敌人、30 个Boss）

LLM 观察玩家行为 →

  玩家A：操作好但解谜慢
  → 减少解谜类任务
  → 增加高难度战斗
  → 给连招提示

  玩家B：解谜快但手残
  → 减少战斗密度
  → 增加探索和谜题
  → 给更多恢复道具

  玩家C：什么都快
  → 拉高难度曲线
  → 给隐藏挑战
  → 引入新机制
```

**内容池没变。但每个人的体验完全不同。**

Roguelike 也做这件事——同一个道具池，每局随机组合。

区别在哪？

```
Roguelike 随机分发：
  你死了 → 重开 → 随机洗牌 → 祝你好运
  可能给你神装开局，也可能第一层就劝退

LLM 智能分发：
  你死了 → AI 知道你在哪死的、为什么死
  → 下次少给这种配置 → 但换一种方式再教你一次
```

Roguelike 追求的是「变」。LLM 追求的是「适应」。

Roguelike 是**公平的洗牌**。LLM 是**有目的的排兵布阵**。

---

### Roguelike 的爽点 vs 长期运营的爽点

还有一个更根本的差异。

Roguelike 的激励模型：

```
开局 → 随机拿资源 → 胡了就爽 → 死了就重来 → 期待下一局胡
```

核心驱动力是**抽奖**。

抽到神装那一刻的爆发式快感。

但长期运营的游戏不能只靠这个。

```
胡牌爽 → 5分钟高潮 → 然后呢？
下一局还是胡牌 → 阈值提高 → 需要更胡 → 边际递减
```

抽奖式的快乐有天花板。越胡越难胡。

长期运营的游戏靠的是另一套东西：

```
不是「抽到好东西」的爽
而是「我变强了」的踏实
不是「这局神装」的惊喜
而是「这是我的世界」的归属感
```

| | Roguelike | 长期运营游戏 |
|---|---|---|
| 驱动力 | 抽奖期待 | 成长感 + 归属感 |
| 时间尺度 | 30-60 分钟一局 | 几个月到几年 |
| 失败代价 | 重开，不心疼 | 投入了时间，不能轻率 |
| 变化来源 | 随机洗牌 | 有方向的变化 |
| 内容复用 | 随机组合 = 耐玩 | 重复 = 流失 |

所以 LLM 分发不能只是「更聪明的洗牌」。

### LLM 分发要服务的是成长感，不是抽奖感

```
❌ Roguelike 式：「这局运气真好！」
   → 玩家感谢运气，不是感谢游戏。

✅ 长期运营式：「这个游戏的节奏好像懂我。」
   → 玩家不觉得有什么在背后操作，只觉得玩得顺。
```

怎么做？

关键是让变化**有方向**。

```
不是随机组合房间
而是根据你昨天的表现，今天的开局就调整了

不是随机给道具
而是你一直不用的那个机制，今天悄悄给了一个温柔的教学场景

不是随机出 Boss
而是你上次卡的地方，这次换了一个能检验你是否真学会了的变体
```

Roguelike 的随机没有记忆。LLM 的分发有。

打完一局 Roguelike，下一局清零。

但长期运营的游戏，LLM 记得——记得你怕什么、会什么、上次在哪放弃的。

**一个有长期记忆的 LLM 分发器，本质上就是一个不会遗忘的「私人教练」。**

---

## 难度曲线不再是一条线

传统游戏：

```
难度
  │        ╱
  │      ╱
  │    ╱    ← 所有人都走这条
  │  ╱
  └────────── 时间
```

LLM 分发后：

```
难度
  │      ╱ 玩家C（激进型，拉满）
  │    ╱╱
  │  ╱╱ 玩家A（稳扎稳打）
  │╱╱
  │╱   玩家B（缓慢上升，多给练习）
  └────────── 时间
```

**难度曲线从「一条固定线」变成「每人的专属曲线」。**

---

## LLM 观察什么

不需要复杂的数据管道。一句话扔进去：

```
玩家过去5分钟的行为：

- 击败了3个敌人，平均耗时 8秒，受伤 2 次
- 跳过了 1 个可选谜题
- 在岔路口选择左边 2 次
- 背包里还有 3 个血瓶没用

→ 下一个房间该放什么？
```

LLM 的答案可能是：

```
这个玩家战斗能力 OK，但不太探索。
下一个房间放一个隐藏宝箱（可跳过），
里面放一个需要解谜才能拿到的稀有武器。
用奖励引导探索行为。
```

**不是写新内容。是从策划的内容池里挑。**

---

## 内容池长什么样

策划不再设计「第一关 → 第二关 → 第三关」。

而是设计一个**标签化的内容池**：

```json
{
  "id": "room_042",
  "type": "combat",
  "difficulty": 0.6,
  "enemies": ["骷髅兵 x3"],
  "rewards": ["金币 x50"],
  "tags": ["近战", "群殴", "低难度"],
  "prerequisite_skills": ["格挡"],
  "teaches": []
}
```

```json
{
  "id": "room_073",
  "type": "puzzle",
  "difficulty": 0.8,
  "mechanics": ["重力翻转"],
  "rewards": ["隐藏武器 x1"],
  "tags": ["解谜", "探索", "奖励驱动"],
  "prerequisite_skills": ["重力翻转已教学"],
  "teaches": ["重力翻转进阶"]
}
```

然后 LLM 的工作变成：

```
玩家状态 → LLM → 从内容池挑下一个房间 → 玩家进入 → 收集数据 → 更新玩家状态 → 继续循环
```

这个循环，Roguelike 已经跑通了半程。

《哈迪斯》每个房间选之前，系统已经知道房间类型、奖励、难度——这就是标签化内容池。但「选哪个」用的是随机数。换成 LLM，唯一变了的是**决策谁来做**。

---

## 内容池够大吗

有一个绕不开的问题：

**TikTok 有海量 UGC。游戏内容只有开发者做。**

TikTok 每天新增几百万条视频。你的内容池里只有 200 个房间。

重新排序 200 个房间——能玩出多少花样？

这个类比确实有一个关键差异。但游戏的解法也不同。

### 差异一：TikTok 内容不可变，游戏内容可参数化

TikTok 的推荐只能「选视频」，不能「改视频」。

但游戏里，一个房间不只是「一个房间」。

```
同一个房间模板：
  敌人组合 A → 近战教学
  敌人组合 B → 远程教学
  敌人组合 C → Boss 前压力测试

  同一个 Boss：
    血量 × 0.7 + 攻击欲望 × 0.5 → 新手版
    血量 × 1.0 + 新增 1 个招式 → 标准版
    血量 × 1.3 + 二阶段 → 挑战版
```

一个内容模板乘以参数组合，放大的不是加法，是乘法。

```text
200 个房间模板
  × 3 种敌人组合
  × 3 个难度档位
  × 2 种奖励倾向（战斗奖励 / 探索奖励）
  ─────────
  = 3600 种实际体验
```

**TikTok 靠用户量撑内容池。游戏靠参数化撑体验空间。**

### 差异二：游戏的重复看到是有意义的

TikTok 看同一个视频两次 = 无聊。

但游戏里，同一个房间打第二次——

```
第一遍：手忙脚乱，残血过
第二遍：知道刷怪位置了，无伤过
```

**这不是重复。这是成长。**

同一个内容，玩家能力变化了，体验就变了。

所以游戏内容的「需求量」天然比短视频低。

### 差异三：组合不是加法，是指数

这也是为什么前面强调「组合生成」。

```text
50 NPC × 100 道具 × 30 线索

如果 AI 只做分发：
  → 150 种内容（互相独立）

如果 AI 做组合生成：
  → 15 万种连线（策划不用提前写）
```

**分发解决「选什么」。组合解决「连起来是什么」。**

内容池不需要 TikTok 那么大。它需要的不是数量，是**元素之间的可连接性**。

## 攻略怎么办

还有一个问题不太常被聊到，但它很要命：

**每个人的体验不同 → 攻略怎么写？**

```
玩家A卡住了，上网搜：
  「第三章 Boss 怎么打」

但第三章 Boss——
  你是骷髅王，他是冰龙，我是双刀刺客。

攻略帮不上忙。
```

### 这不是新问题

Roguelike 早就在面对这件事了。

《以撒的结合》《哈迪斯》《杀戮尖塔》——

每一局都不一样。但攻略仍然存在。

怎么做到的？

```
❌ 攻略不写「第 3 关怎么过」
✅ 攻略写「这把武器怎么用」「这个 Build 怎么搭」「这个敌人怎么读招式」
```

**攻略从教「过关」变成教「理解系统」。**

魂系游戏也是。

没人写「从篝火 A 到篝火 B 的路线」（每个人死的位置不一样）。

大家写「弹反时机」「背刺判定」「这个 Boss 的出招表」。

### 这才是更好的攻略

```
传统攻略：
  步骤 1：去左边房间
  步骤 2：捡起钥匙
  步骤 3：开门

  → 玩家不动脑子，照着做，然后忘了。

系统级攻略：
  钥匙一般藏在可选路径里
  听声音能判断附近有没有隐藏房间
  逆时针绕 Boss 比顺时针安全

  → 玩家理解逻辑，不管遇到什么变体都能应对。
```

第一个像**拐杖**，拿掉就不会走路。

第二个像**教练**，教会了终身受用。

### AI 分发反而推着攻略升级

```
传统游戏 → 攻略可以偷懒 → 步骤清单
AI 分发游戏 → 攻略偷不了懒 → 必须讲系统和方法
```

这不是攻略体系的崩溃。

这是攻略从「操作手册」变成「战术教材」。

### 还有一个解法：AI 自己就是攻略

LLM 分发器知道给你的是什么。

那它也能给你提示。

```
玩家卡了 →
  AI：「你目前面对的骷髅王弱火。
      你的背包里有一把没升级的火焰剑。
      要不要试试？」

  ← 不是通用攻略。是针对你这一局的专属提示。
```

**攻略的内化。**

社区攻略是外部 wiki。AI 攻略是内置在游戏里的声音。

两者可以共存——社区讲大道理，AI 讲当前这一把。

## 不只是难度

LLM 分发还可以控制：

### 节奏

```
玩家连续战斗了20分钟
→ 安排一段叙事/探索/休息
→ 避免战斗疲劳
```

### 情绪

```
玩家刚打完一个Boss，热血沸腾
→ 趁热给一个时间紧迫的追逐战
→ 保持心流

玩家刚解完一个难谜题，烧脑
→ 给一段爽快的无双式战斗
→ 释放压力
```

### 教学

```
玩家某机制一直没用对
→ 安插一个「必须用这个机制」的低难度房间
→ 不提示，用关卡本身教学
```

---

## 一个具体例子

策划做了 200 个房间。

玩家 A 玩到的顺序可能是：

```
战斗(简单) → 战斗(简单) → 谜题(教学) → 战斗(中等)
→ 探索奖励 → Boss(入门) → 叙事 → 战斗(中等) ...
```

玩家 B 玩到的顺序：

```
战斗(简单) → 战斗(简单) → 战斗(简单) → 战斗(中等)
→ 战斗(中等) → Boss(入门) → Boss(入门) → 战斗(困难) ...
```

**两个人都觉得自己玩的「就是游戏本来的顺序」。**

这才是好分发的标志——**你感觉不到分发器的存在。**

## 和传统推荐算法的区别

| | 传统推荐 | LLM 分发 |
|---|---|---|
| 输入 | 评分、点击、时长 | 行为序列、上下文、自然语言描述 |
| 输出 | 内容 ID | 内容 ID + 理由 + 参数调整 |
| 可解释 | 弱（协同过滤黑盒） | 强（可以追问为什么选这个） |
| 冷启动 | 需要大量历史数据 | 几句话的行为描述就能开始工作 |
| 动态调整 | 需要重训练 | 实时，每一轮对话都是新判断 |

---

## 代价是什么

### 延迟

每一轮房间选择都要调一次 LLM → 延迟。

解决：

```
预判：一次要接下来的 3-5 个房间
异步：玩家在前一个房间时，后台算出下一个
fallback：LLM 超时就用规则兜底
```

### 成本

每次房间选择调 API 不现实。

解决：

```
本地小模型（7B 足够做内容排序）
云端大模型异步分析长线趋势
小模型做实时分发，大模型做策略调整
```

### 不可控

LLM 的输出不够稳定。

解决：

```
输出格式严格约束（JSON Schema）
不是让 LLM「自由发挥」，是让它「从池里打分排序」
```

### 不确定性

前面三个代价是工程问题。

这一个不是。

**传统程序是确定性的。**

```
玩家走到坐标 (32, 64) → 触发事件 A → 播放动画 B
你测 100 遍，它触发 100 遍。
```

**LLM 分发的系统不是。**

```
玩家走到这个房间 → LLM 决定下一个是什么
你测 100 遍，可能是 100 个不同的结果。
```

程序员最深的恐惧不是「AI 写代码比我快」。

是**「我不知道这个系统会干什么」。**

### 为什么这么难受

传统 Bug：

```
预期：扣 50 血
实际：扣了 -50 血 → 回血了
原因：符号写反了
修：改个负号，搞定。
```

问题可以复现。复现了就能修。

LLM 分发的 Bug：

```
玩家 #472：
  在第 38 个房间卡住了，Boss 数值过高，打不过。

为什么？
  → 因为前面的房间组合导致他的 DPS 成长慢了 15%
  → 为什么 DPS 慢？
  → 因为 AI 判断他探索型，多给了谜题，少给了战斗
  → 但谜题没奖励武器，战斗才给
  → 结果他 DPS 曲线落后了

这不是一个 bug。这是一条因果链。
```

没法在测试环境复现。

因为同样的玩家行为序列可能根本不会再出现。

### 传统 QA 的失效

```
传统 QA：
  跑关卡 1-5 → 确认难度平滑 → 通过

LLM 分发后：
  5 个关卡 → 3600 种组合 → 每种组合有不同的难度曲线
  每种难度曲线 × 不同的玩家行为 → 不可能穷举
```

不是「没测到」。是**不可能全测完**。

### 程序员需要换一套工具

```
❌ 传统调试：
   复现 → 定位 → 修改 → 验证

✅ LLM 系统调试：
   不是修单个 case → 是修决策逻辑
   不是测所有组合 → 是测边界
   不是断言「结果是 A」→ 是断言「结果在可接受范围内」
```

**从确定性系统到概率性系统。**

这就是为什么程序员恐惧。

不是因为 AI 抢工作。

是因为我们学了十几年的东西——**控制、预测、确定性**——在这个架构里，不再适用了。

---

## 三个真正有意义的方向

把前面的讨论收拢一下。

「AI + 游戏内容」的探索，不是一条路，是三条。

### 方向一：策划控制节拍，AI 控制细节

```
策划定：
  第10-15分钟 → Boss战
  第15-20分钟 → 叙事喘息

AI 定：
  这个Boss用什么招式组合
  这段对话用什么语气
  这个场景里 NPC 站左边还是右边
```

策划做**骨架**，AI 填**血肉**。

前面讲的非线性叙事 + AI，就是这条路。

策划说「这里需要一个转折」，AI 负责写出这个转折。

---

### 方向二：AI 做玩家建模，策划做内容决策

```
AI 的活：
  这个玩家是探索型还是战斗型
  他的挫败阈值在哪
  什么机制他还没掌握
  → 输出一份「玩家画像」

策划的活：
  看到画像后，决定这个玩家适合什么内容
  调什么参数
  走哪条分支
  → 最终决策权在策划手里
```

米哈游就在走这个方向。

玩家数据 → AI 分析 → 策划决策 → 内容投放。

AI 是**情报系统**，策划是**指挥官**。

---

### 方向三：AI 做运行时适配，策划预设边界

```
策划预设：
  这个关卡，难度可以在 0.3 ~ 0.8 之间浮动
  最多连续给 3 场战斗，不能更多
  战斗和探索的比例维持在 6:4 到 4:6 之间
  Boss 战绝不能连续出现 2 次以上

AI 运行时：
  在边界内，根据玩家当前状态微调
  这个敌人血量减 10%？在边界内，可以
  跳过这个 Boss？不行，策划没给这个弹性
```

**AI 有自由度，但笼子的大小是策划定的。**

这就是本文一直在讲的「LLM 做分发」——分发不是乱发，是在边界内发。

---

### 三条路的关系

```
方向二（AI玩家建模）
      ↓ 提供情报
方向一（策划控节拍 + AI控细节）
      ↓ 定义骨架
方向三（AI运行时适配，策划预设边界）
      ↑ 在边界内分发
```

三条路不是互斥的。一个成熟的游戏，三层可以同时跑。

但无论哪条路，**最终决策权都在策划手里。**

AI 是工具。节奏是策划的事。

---

## 但生成不是禁区

前面一直在说「AI 不要乱生成」。

但这不意味着 AI 完全不能生成。

关键是：**什么时候生成。**

Roguelike 玩家都知道一件事：两个不起眼的道具，凑在一起突然无敌了。《以撒的结合》里这种现象叫「道具协同」。

这不是策划提前写好的。是道具的规则碰撞出来的。

LLM 把这种协同从**道具层面**拉到了**叙事层面**。

### 选项足够时，组合爆炸 = 新内容

回到前面的内容池：

```json
{"id": "npc_001", "role": "商人", "mood": "贪婪"},
{"id": "npc_002", "role": "守卫", "mood": "正直"},
{"id": "item_017", "type": "信件", "clue": "提到失踪的王子"},
{"id": "item_023", "type": "钥匙", "clue": "刻着龙纹"},
```

策划往池子里放了 50 个 NPC、100 件道具、30 条线索。

这些东西之间本来没有故事。

但如果玩家在某个档口——

```
拿了信件 + 遇到了贪婪商人 + 钥匙上刻着龙纹
```

这三个东西放在一起，没有任何策划预先写好的剧情。

但 LLM 可以当场生成：

```
商人的贪婪 + 信件的秘密 + 龙纹钥匙 →
「商人告诉你：想要龙纹宝藏？我认识一个人见过它。
  但你得先帮我送一封信给王子——哦对了，王子失踪了是吧？
  那这封信更值钱了。」
```

**这既不是策划写好的，也不是 AI 乱编的。**

三条既有内容碰撞在一起，一条新剧情线「送信任务」凭空出现。

---

### 这和控制不矛盾

```
策划控制：
  商人必须是贪婪的
  信件一定指向王子失踪
  钥匙上的龙纹必须存在

AI 控制：
  这三个东西放在一起能擦出什么火花
```

策划保证每一条信息都是**对的**。

AI 保证这些信息**组合之后**仍然自洽。

---

### 和前三条方向的关系

```
方向一：策划控节拍 → 确保「什么时候该有点事」
方向二：AI 做玩家建模 → 确保「这个玩家会被什么打动」
方向三：AI 做运行时适配 → 确保「给什么不会超出玩家能力」

组合生成 ← 三层都到位之后，自然发生的事情
```

玩家是否触发这条「送信任务」，取决于：

- 方向一的节拍：冲突发生得太早？太晚？
- 方向二的建模：这个玩家是任务型还是探索型？对商人有信任吗？
- 方向三的边界：AI 生成的任务会不会超出 10 分钟？会不会连续给任务？

**三层兜底，AI 才被允许在边界内生成。**

这不是「自由发挥」。这是「有约束的涌现」。

---

### 关键区别

```
❌ AI 从零编故事 → 不可控，节奏崩
✅ AI 从既有内容的组合中生成新连线 → 可控，逻辑自洽

❌ AI 替代策划 → 没有人类意图，游戏失魂
✅ AI 在策划搭的积木上搭新结构 → 基石是人定的

❌ 提前写死所有可能 → 组合爆炸，不可能穷举
✅ 运行时动态生成 → 50×100×30 = 15万种组合，AI 每次只算一种
```

---

## 现在到哪了：一个非穷举的技术图谱

这一套想法有实际的探索吗？有。但散落在不同领域，还没有人把它们拼在一起。

### 非 LLM 的先驱

在 LLM 出现之前，就有人在做「AI 内容分发」了——

**Left 4 Dead 的 AI Director（2008）**

```
不是让 AI 写新敌人。
是让 AI 决定：现在该出多少怪、在哪出、BGM 切不切。

监控每个玩家的「压力值」
  → 压力太高？停一波怪，给补给
  → 压力太低？来一波高潮，把 BGM 拉起来
```

Valve 称之为「程序性叙事」——故事不是编剧写的，是系统根据玩家状态**当场编排**的。

这就是「内容分发」的雏形。不是生成，是编排。

**生化危机 4 的动态难度（2005）**

```
玩家连死三次 → 敌人血量偷偷缩 20%
玩家无伤过 → 下一波多刷一个怪
```

玩家感知不到。但它一直在后台跑。

三上真司管这个叫「看不见的导演」。

**《哈迪斯》的房间选择（2020）**

标签化的内容池 + 选择界面。虽然不是 AI 在选，但房间的数据结构（类型、难度、奖励）已经完全是「内容池思维」。

---

### LLM 相邻探索

这些不是直接做「LLM 分发」，但从不同方向摸过来了——

**Stanford 的 Generative Agents（2023）**

那篇著名的「25 个 AI 小人」论文。

```
小镇里有 25 个 Agent，各有性格、记忆、日程。

Agent A 在筹划情人节派对 →
Agent B 路过，不知道这事，但注意到了异常 →
第二天 Agent B 在咖啡馆主动问 Agent A：「昨晚你厨房的灯一直亮着？」

——这个对话没有任何人写，是两个 Agent 的记忆碰撞出来的。
```

这和前面讲的「组合生成」完全是一个逻辑：Agent 的记忆 × Agent 的性格 → 新对话。

区别是这篇论文在模拟**社群**，而我们讨论的是用它服务**单个玩家**。

**Inworld AI / NVIDIA ACE（2023-2025）**

给 NPC 接上 LLM，让他们能自由对话。重点是**生成**对话内容，不是分发。但他们解决了一个核心问题：如何给 LLM 角色设定边界（性格、知识范围、不能说的东西）——和方向三「策划预设边界」是一回事。

**Hidden Door（2024）**

LLM 做游戏主持人（GM）。玩家输入行动，LLM 叙事回应。更偏「生成」而不是「分发」。但它的内容池概念很清晰——用现有 IP 的世界观作为边界，AI 在里面自由扮演。

---

### 大厂在做什么

**米哈游** — 方向二（AI 玩家建模 → 策划决策）。玩家行为分析 + 内容投放策略，AI 做分析辅助，决策权在策划。

**网易（逆水寒手游 2023）** — AI NPC 自由对话。玩家可以打字跟 NPC 聊，NPC 用 LLM 回应。更偏「生成」侧，但 NPC 的记忆和行为是受策划预设约束的。

**Ubisoft Ghostwriter（2023）** — AI 生成 NPC 的随机对话（barks），策划审核后入库。文案级应用，不涉及分发逻辑。

**Netflix Games / 云游戏方向** — 在探索个性化叙事分支。和 TikTok 分发逻辑最接近：用户偏好画像 → 推荐剧情方向的偏好。

---

### 真正缺的是什么

前面这些都摸到了边。但没有一个项目在同时做这三件事：

```
✅ 内容池是策划设计和标签化的（不是 AI 生成的）
✅ 分发决策是基于玩家行为理解的（不是随机的）
✅ 边界是策划预设的（不是 AI 自由发挥的）
```

Left 4 Dead 的 AI Director 最接近这个定义——但它不「理解」玩家，只看压力值这一维数据。LLM 可以让 AI Director 从「看仪表盘」升级到「读懂你」。

**这也是为什么这篇文章要写——不是因为已经有了答案，而是因为把散落各地的拼图放在一起，能看到一张还没人拼完的地图。**

---

## 总结

```
AI 自由生成 → 不可控，节奏崩，很多人已经踩过坑了
AI 智能分发 → 内容池不变，体验完全不同，还没什么人做
AI 组合生成 → 选项够了就涌现新剧情，是分发的自然延伸
```

TikTok 证明了：**分发能力 ≥ 内容能力。**

同样一堆视频，换一个推荐算法，DAU 翻倍。

游戏也是。

同样 200 个房间，换一个 LLM 分发器——

再加上当玩家的选择足够多时，LLM 当场把既有内容织成新剧情——

每个玩家都会觉得「这个游戏就是给我做的」。
